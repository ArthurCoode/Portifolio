# 🌐 Portfolio — Arthur Marques

## 📌 About the Project

This is my personal portfolio website, created to showcase my projects, services, certifications, and professional information.  
The layout is built with a focus on **performance, clean code, responsiveness, and an excellent user experience**.

The project includes:

- 🌎 Multi-language system (EN/PT)  
- 📱 Fully responsive interface  
- 🤖 Built‑in interactive chatbot (MarquesBot)  
- 🎨 Modern and minimal design  
- 🧩 Sections for personal and GitHub projects  
- 📝 Well‑structured content and smooth animations  

👉 **Live Demo:** https://marquescode.com  
👉 **Repository:** https://github.com/ArthurCoode/Portifolio

---

## ✨ Features

### 🌍 Multi‑Language Support  
All text elements include `data-en` and `data-pt` attributes, enabling dynamic translation.

### 🤖 Interactive Chatbot (MarquesBot)  
A floating chatbot with predefined quick messages capable of answering questions related to:

- Stack  
- Projects  
- Contact  
- Experience  
- Opportunities  
- GitHub and LinkedIn links  

### 🧠 Updates Feed  
A dynamic and filterable section for posting updates and improvements to the portfolio.

### 💼 Project Showcase  
Includes:

- Institutional websites  
- Corporate projects  
- Personal projects  
- Java REST APIs (Spring Boot)  

### 📬 Contact Form  
Functional contact form using **EmailJS**, featuring real-time success messages.
