## ✨ Funcionalidades

### 🌎 Sistema Multilíngue

O portfólio possui suporte para **Português e Inglês**, permitindo alternar o idioma da interface de forma dinâmica.

Os conteúdos são organizados utilizando atributos `data-pt` e `data-en`, facilitando a manutenção e tradução das informações.

### 🤖 MarquesBot

O portfólio possui um chatbot interativo desenvolvido para facilitar a navegação e apresentar informações sobre meu perfil profissional.

O **MarquesBot** pode responder perguntas relacionadas a:

* 💻 Tecnologias e stack
* 🚀 Projetos
* 💼 Experiência profissional
* 📚 Formação e estudos
* 📬 Contato
* 💡 Oportunidades profissionais
* 🔗 GitHub
* 🔗 LinkedIn

### 🧠 Feed de Atualizações

Uma seção dinâmica para apresentar novidades, melhorias e atualizações relacionadas ao meu desenvolvimento profissional e ao próprio portfólio.

O conteúdo pode ser filtrado para facilitar a navegação.

### 💼 Showcase de Projetos

A seção de projetos apresenta aplicações desenvolvidas durante minha evolução como desenvolvedor.

Entre elas:

* 🌐 Sites institucionais
* 💼 Sistemas corporativos
* 🤖 Projetos com Inteligência Artificial
* ☕ APIs REST com Java e Spring Boot
* 🖥️ Aplicações Full Stack
* 📚 Projetos acadêmicos
* 🚀 Projetos pessoais

### 📬 Formulário de Contato

O portfólio possui um formulário de contato integrado ao **EmailJS**, permitindo que visitantes enviem mensagens diretamente pelo site.

Também são exibidas mensagens de confirmação após o envio.

# 🚀 Projetos em Destaque

## 🤖 TranscreveAI

Plataforma desenvolvida para transformar reuniões em **transcrições e insights utilizando Inteligência Artificial**.

### Tecnologias utilizadas

* Next.js
* TypeScript
* Supabase
* Groq API
* Whisper Large V3
* LLaMA
* Web Audio API
* APIs REST

O sistema foi desenvolvido para capturar o áudio de reuniões, realizar a transcrição e gerar informações relevantes automaticamente.

🌐 **Projeto:** [transcreveia.com](https://www.transcreveia.com/)
